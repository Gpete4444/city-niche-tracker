Rover 2.8 — Operator flowcharts

One-time setup, then per-site run. Forms use the Rover forms Worker — not Web3Forms.

1. One-time setup

Once per machine / account · OPERATOR-ONE-TIME-SETUP.md

flowchart TD
  A[GitHub invite + Git + Cursor] --> B[Clone Rover 2.8 + npm install]
  B --> C[Gear → Account setup
APIs, Maps, Apify, OpenAI, Anthropic]
  C --> D[gh auth login + GitHub owner]
  D --> E[Cloudflare account ID + user API token
include D1 Edit]
  E --> F[Register workers.dev subdomain]
  F --> G[Account setup → Lead notify email
Gmail / Zoho / etc.]
  G --> H[npm run rover]
  H --> I[Phone/Form → Set up inbox
Forms Worker — not Web3Forms]
  I --> J[Twilio rover-voice + Deploy All
SID token forward in Account setup
webhook stays in .env]
  J --> K[Phone → Save spoken fallback]
  K --> L{Settings greens?}
  L -->|No| M[Fix red rows / restart Rover]
  M --> L
  L -->|Yes| N[One-time setup done]
  N --> O[Optional later: Connect GSC]
  N --> P[Go to site runbook → build first site]

  style I fill:#dbeafe,stroke:#2563eb
  style N fill:#dcfce7,stroke:#16a34a
  style P fill:#fef9c3,stroke:#ca8a04

2. Running the app

Each new site · OPERATOR-SITE-RUNBOOK.md

flowchart TD
  S[npm run rover · open dashboard
reload with Ctrl+Shift+R] --> R[Discovery / Research → pursue]
  R --> SC[Site-Config: name, domain, services
City 1 Save niche default · City 2+ Load]
  SC --> PH[Provision ranking number
leave area-code box blank]
  PH --> W[Content: Preset C → Write site]
  W --> PG{First city for this niche?}
  PG -->|Yes| SKIP[Load photo group → Skip
Accept · Skip stock off]
  PG -->|No| LOAD[Load photo group → niche master
Load on Accept · Skip stock on]
  SKIP --> ACC[Accept content]
  LOAD --> ACC
  ACC --> IMG[Review images · Filter Empty
Fill materials/process before master]
  IMG --> PREP[Prepare preview + QA
or Replace master if this city is the gold set]
  PREP --> DOM[Buy domain in Cloudflare
Domains → Overview → Add domain · Active]
  DOM --> VRF{Notify destination Verified?
once per inbox}
  VRF -->|No| VRF2[Click Cloudflare verify link in inbox]
  VRF2 --> VRF
  VRF -->|Yes| LCH[Run launch
Auto ship + Connect domain and email]
  LCH --> SMOKE[Live form smoke-test
→ notify inbox + Phone/Form]
  SMOKE --> IDX[Indexing: GOOGLE INDEX → REQUEST INDEXING
homepage + 2–3 services · Mark done]
  IDX --> DONE[Launched · site live]
  DONE --> CHARTS[Launched: Cluster tree + daily charts]
  CHARTS --> NEXT{Another city same niche?}
  NEXT -->|Yes| R2[Reuse forms inbox + LEAD_NOTIFY
+ Load niche default + Load master]
  R2 --> R
  NEXT -->|Gap-fill then share| GAP[Fill Empty → Replace master
→ Load master on siblings → Push]
  NEXT -->|Later updates| UPD[Prepare preview → Push updates]
